# Candidates and Solutions

<a id="evidence-and-limits"></a>
<a id="local-api"></a>
<a id="private-solutions"></a>

The Electron preview saves private reasoning and Run evidence. It does not yet
provide Candidate selection, Solution snapshots, walkthrough export or official
submission controls. A completed Run is an operation result, not a verified
Challenge answer.

In the canonical domain, a **Candidate** is a private, revisioned answer selection
for a Stage. A **Solution** preserves a chosen result, explanation and contributing
evidence. Official submission and evaluation are separate records; local evidence
does not establish correctness or publication.

Use [the notebook](notebook.md) to retain current findings and
[Run history](reference/desktop-runs.md) to inspect their exact inputs and outcomes.
Full entity rules belong to [the domain contract](reference/desktop-domain.md);
implementation is tracked in [#50](https://github.com/cubearc/play/issues/50).

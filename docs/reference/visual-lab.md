# Native image and operation adapters

<a id="raw-stream-transforms"></a>
<a id="visual-lab-implementation-and-verification"></a>

The preview displays imported PNGs and runs compatible Core-registered operations on macOS and Linux.
The image preset reads coordinates 0,0 with palette expansion disabled; its typed
byte result is independent of text/caption Runs. Core catalog discovery alone does not establish a native adapter.

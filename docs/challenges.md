# Challenges and local Stages

<a id="local-challenge-contract"></a>
<a id="private-stage-candidates"></a>

Create local Stages with **New Stage** inside an Exploration. Add your own
[text, images or files](workspace.md) and [save reasoning](notebook.md); no Challenge
manifest or online participation is required for this notebook workflow.

The Electron preview does not import Challenge packages, clone a published
edition, unlock remote content or submit answers. It has no hosted forms,
official evaluation, ranking or reward workflow. Manually assembling clues
locally does not create an official participation record.

A canonical local Stage may later refer to a published edition and source stage,
while retaining its own local identity. Private Candidates/Solutions and official
outcomes remain distinct. See [the domain contract](reference/desktop-domain.md)
for those identities and the [milestone](https://github.com/cubearc/play/milestone/3)
for integration status.

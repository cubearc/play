# Play documentation

Read applicable instructions and the
[shared authoring guide](https://github.com/cubearc/docs/blob/main/content/contributing/documentation.md).
With a sibling docs checkout, prefer its `content/contributing/documentation.md`.

Find the existing task page before creating one. Keep first-use instructions
separate from API, storage and isolation reference. Operation metadata and
algorithms remain owned by Cube.

Check examples and UI names against the actual source. Update affected tasks and
`docs/SUMMARY.md`, preserve old links, and run relevant link/example checks.
Keep unsupported platforms and private/local verification described accurately.

Respect review-only and planning-only requests. Report actual changes and evidence.
